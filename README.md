# Student Task Manager

## Project Description
A browser application for managing student tasks.

## Team Members
- Aiman Khan — itsaimankhan
- Collaborator account — aymennkhan

The collaboration workflow was completed individually using
two accounts with the instructor's permission.

## Features
- Add tasks with a title and description
- Display tasks
- Mark tasks completed or pending
- Delete tasks
- Search titles and descriptions without case sensitivity

Tasks are stored in memory. Refreshing the page clears them.

Download or clone the repository and open index.html in Chrome.
No installation or backend server is required.
